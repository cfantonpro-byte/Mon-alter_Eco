# Palette sémantique des résultats

Cette palette est réservée aux pages `study.html` : Potentiel, Pistes et Synthèse.

## Correspondances

- `profile-balance.png` : profil équilibré
- `security-lock.png` : priorité à la sécurité
- `performance-target.png` : rendement recherché
- `horizon-calendar.png` : horizon de placement
- `savings-capacity.png` : capacité d'épargne
- `diversification.png` : diversification / assurance-vie multisupport
- `solution-per.png` : plan d'épargne retraite
- `solution-pea.png` : plan d'épargne en actions
- `solution-rental.png` : immobilier locatif
- `solution-scpi.png` : investissement immobilier mutualisé en SCPI
- `solution-protection.png` : prévoyance et protection des proches
- `studyz-demand.png` : demande en logement étudiant
- `studyz-management.png` : gestion accompagnée
- `studyz-impact.png` : impact social et éducatif
- `location-france.png` : implantation dans plusieurs villes françaises
- `priority.png` : recommandation prioritaire / prochaine étape
- `capacity-wallet.png` : capacité d'investissement
- `personal-analysis.png` : analyse personnalisée
- `advisor-support.png` : accompagnement par un conseiller

Les libellés restent en HTML afin de garantir leur lisibilité et leur accessibilité. Les boutons, puces et jauges fonctionnels sont dessinés en CSS ; les images ne servent qu'à porter un sens métier.

## Prompts sources

Les deux atlas sources ont été générés comme des grilles strictes, sans texte, avec fond alpha transparent, palette bleu nuit / or et rendu 3D premium cohérent avec Mon Alter-Eco. `profile-atlas.png` regroupe les signaux du profil et les solutions ; `studyz-atlas.png` regroupe les bénéfices Stüdyz et les éléments de conseil. Les fichiers individuels sont des découpes de ces atlas, conservées dans le même dossier.
